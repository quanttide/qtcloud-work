## 产物「类别 / 名字」两轴

- **背景**：规格新立产物类别（`report` / `journal` / `specification` 一类，见领域仓 `docs/specification/piece/category.md`），产物本身另有名字（如《量潮知识工作报告》）。工具箱的 `Artifact` 只认名字加规格；cli 的 `Task::artifact(category)` 把类别当名字传给 `Artifact::named`，只用来算落点。
- **选项**：甲，`Artifact` 纳入类别，落点按类别算；乙，`Artifact` 不纳类别，落点按名字算。
- **影响**：落点算法与 `--json` 键，cli 与 studio 两侧同批改。
- **建议**：乙；归属规格，端侧跟随。规格已写「产物 = 名字 + 规格」「类别不参与落点，落点由工作区按名字算」（`piece/artifact.md`、`piece/category.md`）。本侧把 `Task::artifact(category)` 改成按名字，与工具箱同批。

## `Workflow` 的 `name` 与文件名一致

- **背景**：`Workflow::of(值)` 的工作流名取自 `name` 字段；工作区按名字取定义。定义里两者不一致时静默取不到，流水判定返回空。
- **选项**：甲，工具箱 `validate` 收文件名核一致；乙，本侧 `load` 挡。
- **影响**：甲改工具箱 Rust 与 Dart 两侧，覆盖全部调用方；乙只改 cli，studio 的同一处仍开着。工具箱约定「不碰文件系统，需要文件事实时用回调注入」，收文件名与该约定相容。
- **建议**：甲；归属工具箱。

## cli 用词：资产表与产物类别

- **背景**：cli 的 `src/artifact/` 装的是第二大脑资产表二十格（陈述型 11、程序型 9），类型是 `Asset { category, name }`；文档与注释写「资产表 / 资产」。规格的新词是「产物」（名字 + 规格）与「产物类别」（`report` / `journal` 一类）。两者不是一物：资产表说的是工作区里有哪些文档格，产物说的是任务执行的目标。`artifact` 一名在两侧指的不是同一件东西。
- **选项**：甲，分开命名——工作区的文档格归「资产」、任务产出归「产物 / 产物类别」，cli 的 `src/artifact/` 按实改名（如 `asset/`）；乙，统一到「产物类别」，资产表也叫产物类别。
- **影响**：目录名、文档、`catalog` / `audit` 的输出与 `--json` 键。
- **建议**：甲；归属规格与端侧共定。两个概念并存，名字也该有两个；`artifact` 留给规格里的产物，资产表另有其名。

## `prompts` 两侧的两段话

- **背景**：cli `src/prompts.rs` 与 studio `lib/repositories/local/prompts.dart` 各有一份给智能体的两段话，头注释互相矛盾（各写「只是命令行这一侧的说法」「只是工作台这一侧的说法」）。两段话原先在工具箱，工具箱约定「说法不进库」，于是搬回端侧。
- **选项**：甲，合一（落点在规格或手册）；乙，各留一份，写明各自的必含项与差异。
- **影响**：甲要新落点，且与「说法不进库」相抵；乙保持端侧自治，需要把必含项定在规格、去掉互相打脸的注释。
- **建议**：乙；归属规格定必含项，端侧各自表述，不追求逐字一致。

## 发布线：cli 与 studio 一条还是两条

- **背景**：cli 走 `cli/v*`（crates.io 与三平台二进制），studio 走 `studio/v*`（Flutter Web 到 OSS 与 CDN）。两侧是一件事的两面，共用工具箱。
- **选项**：甲，一条线（同一个 tag 与版本号）；乙，两条线（各自 tag）。
- **影响**：甲要求两侧同批发、版本对齐，发布物与目标注册表不同要多一层协调；乙允许各自发，靠「工具箱同号与对表一致」约束。
- **建议**：乙；归属平台，由创始人定。

## IaC 归属

- **背景**：平台契约要求 IaC 目录 `manifests/terraform/`；cli 与 studio 都没有，归属未定——cli 的发布物（crates.io 与三平台二进制）与基础设施归本仓还是平台仓。
- **选项**：甲，本仓，与发布同仓；乙，平台仓，集中一处。
- **影响**：甲每仓各管一份；乙需要跨仓发布协调。
- **建议**：待平台契约写明归属再定，本仓不先建 `manifests/terraform/`；归属平台。
