# adapters：边界外的东西

`src/adapters/` 装的是跟「外部」打交道的件。外部指本程序管不着的东西——现在只有一样：命令行 AI `pi`。程序内部的事（工单长什么样、判据怎么判）不归这里。

## 落点

- `adapters/pi.rs`——跟 `pi` 打交道：起进程、把它的输出收成一行、从回答里认「通过 / 不通过」。见 [pi](pi.md)。

## 为什么单开一层

这些件依赖的是外部世界，不是本程序的定义。单开一层，变化才好收口：哪天 `pi` 换成别的命令，只动这一处，上层的 `workers` 不用跟着改。

## 测试

`pi` 的行为由走一步的场景间接覆盖：`tests/order_next.rs`（跑成 / 跑不成）、`tests/criteria_matrix.rs`（审查结论怎么认）。
