# workspace：工作区

`src/workspace/` 管命令行这一侧的两件事：三处位置的默认值，与路径怎么显示给人看。工作区的模型与操作（核对、落点、流水判定）在工具箱里。

## 落点

- `root`——工作区根：给了就用给的，没给就用当前目录；
- `data_dir`——数据仓：给了就用给的，没给就用当前目录下的 `data/`，并把用的是哪个印到标准错误；
- `short`——路径显示：相对工作区根写短一点，不在根底下就原样。

## 与工具箱

`quanttide_work::workspace::Workspace` 是模型侧的工作区，把定义、任务、工件系在一起。核对、落点、流水判定三件都要拿整个工作区才做得了，本侧用 `Workspace::of(定义, 任务)` 组装，操作结果照搬。

「在不在」由端侧判断，工作区不读文件系统——核对与落点都要本侧注入路径事实。
