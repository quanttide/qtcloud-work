# 状态面板

任务页右栏，从上到下五块。

| 块 | 装什么 | 数据来自 |
|---|---|---|
| 状态行 | `运行中 · 3 / 6`、当前步骤、进度条 | 任务流水 + 流程的步骤数 |
| 关联流程 | 跑的是哪条流程，点开回流程页 | 任务文件的 `workflow` |
| 闸门 | 留给人那一步，等人放行 | 任务的 `gates` |
| 产物 | 报告／日志／流水三个落点 | 任务的 `products` |
| 流水 | 最近几条：时间、步骤、一句话 | 任务的 `log` 尾部 |
| 动作 | `走下一步`（`--next`）、`记一步`（`--done`）；⋯ 里 `记日志`（`--journal`）、`导出结果`（`--out`）、`看 JSON`（`--json`）、`干跑`（`--dry-run`） | — |
