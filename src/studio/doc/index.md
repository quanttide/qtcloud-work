—

一、全局框架

```
┌──────────────────────────────────────────────────────┐
│ 顶部栏：工作区切换                                     │
├────────────┬─────────────────────────────────────────┤
│ 左侧导航    │ 主内容区                                 │
│            │                                         │
│ ● 任务      │  任务页：对话 + 任务状态                 │
│ ● 工作流    │  工作流页：对话 + 可视化                 │
│ ● 设置      │                                         │
└────────────┴─────────────────────────────────────────┘
```

· 顶部只有工作区切换。
· 没有全局搜索、通知、用户、新建、任务切换器。
· 任务/工作流的切换在各自页面内部解决。

—

二、任务页

```
┌──────────────────────────────────────────────────────┐
│ 页内顶部：任务切换 / 新建任务                          │
├──────────────────────────┬───────────────────────────┤
│ 左栏：对话                │ 右栏：任务状态              │
│                          │                           │
│ 用户输入目标              │ 状态：待确认流程/运行中/    │
│ AI 先出工作流草案          │      需审批/已完成/失败     │
│ 用户确认 / 修改 / 驳回     │ 关联工作流及版本            │
│ 执行中进展汇报            │ 当前步骤 / 总步骤           │
│ 用户干预、审批、补充       │ 当前节点                   │
│ 最终结果                  │ 进度条                     │
│ 验收确认                  │ 阻塞 / 错误                │
│                          │ 上下文：洗上下文 / 快照      │
│                          │ 操作：暂停/继续/取消/重试    │
│                          │ 保存为工作流               │
└──────────────────────────┴───────────────────────────┘
```

· 任务切换、新建任务放在页内顶部，不占全局顶部栏。

—

三、工作流页

```
┌──────────────────────────────────────────────────────┐
│ 页内顶部：工作流切换 / 新建 / 版本 / 发布 / 运行       │
├──────────────────────────┬───────────────────────────┤
│ 左栏：对话                │ 右栏：可视化                │
│                          │                           │
│ 用户描述工作流需求         │ DAG 画布                   │
│ AI 生成 / 修改工作流       │ 节点：输入/AI代理/工具/     │
│ 解释节点、参数、验收标准    │      条件/并行/循环/审批/输出│
│ 讨论版本、变更、回滚        │ 连线与分支                 │
│ 保存、发布、运行           │ 选中节点显示属性面板        │
│                          │ 模型选择、输入输出 Schema   │
│                          │ 权限/超时/重试             │
│                          │ 代码视图：YAML + JS 切换    │
└──────────────────────────┴───────────────────────────┘
```

· 工作流切换、新建、版本、发布、运行都放在页内顶部。

—

四、跨页关系

```
任务页 ──保存为工作流──▶ 工作流页
工作流页 ──运行──▶ 任务页（新建任务，带入工作流）
任务状态 ──点击关联工作流──▶ 工作流页
```

—

五、路由

```
/tasks/:id        任务页（对话 + 任务状态）
/tasks/new        新建任务

/workflows/:id    工作流页（对话 + 可视化）
/workflows/new    新建工作流

/settings         设置
```

—

六、设计原则

1. 顶部极简：只保留工作区切换。
2. 双核：任务页 + 工作流页。
3. 任务页极简：只有对话和任务状态。
4. 工作流页极简：只有对话和可视化。
5. 流程优先：AI 必须先出流程，用户确认后才执行。
6. 页面内自治：任务切换、工作流切换、新建、版本等都在页内顶部，不上升全局。

一句话：
顶部只有工作区切换；任务页只有对话和任务状态；工作流页只有对话和可视化。
